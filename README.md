# dustyPad releases

Downloads for **dustyPad** — give your old tech a new trick. Turn an old iPad or Android tablet into a macropad and widget board for your Mac.

Get it at **[dustypad.com](https://dustypad.com)** or on [Gumroad](https://mknarciso.gumroad.com/l/dustypad). Each version is listed under [Releases](../../releases).

This repository only holds the app builds. The app checks it to tell you when a new version is out.
